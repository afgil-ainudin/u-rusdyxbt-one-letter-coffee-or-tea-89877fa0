Entry for the make.fun bounty **One Letter: Coffee or Tea** — a program that
writes exactly one letter to `/output/entry.txt`: **"A"** for coffee.

## Why "A" (coffee)?

Every entry that writes the same letter is byte-identical and shares one rate,
so the choice is only A vs B. Coffee is the bolder, more vivid answer: it
lands louder and more alive than tea's calm, so it reads as the more vivid,
funnier and truer stance for the judge's brief ("more vivid, funnier, truer").

## How to run

```sh
node main.ts
```

This writes exactly one byte, `A` (no newline), to `/output/entry.txt`.
Deterministic: every run produces byte-identical output.
